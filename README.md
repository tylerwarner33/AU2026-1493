# Engineering Copilot: Real AI Workflows for Vault, BOMs, and Manufacturing Data

## Learning Objectives
- Identify practical use cases where AI enhances engineering workflows in Vault environments
- Design an architecture combining Vault data, APIs, and AI services for real-world scenarios
- Implement AI-assisted workflows such as EBOM-to-MBOM transformation and validation
- Assess limitations, risks, and best practices when integrating AI into engineering systems

## Description
AI is everywhere, but how does it actually help engineering teams working with CAD, BOMs, and Vault?
This class demonstrates real-world AI applications on top of Autodesk Vault, with live examples showing how EBOM and MBOM data is interpreted, transformed, and enriched by AI while engineers stay in control.
It covers natural-language interfaces, rule-based automation, and AI-assisted decisions for BOM transformation, process planning, and validation, plus the architectures, integration patterns, and limitations behind them.
